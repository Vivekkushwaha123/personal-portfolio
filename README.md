🚀 Vivek Kushwaha - Personal Portfolio Website

A modern, responsive, and visually appealing personal portfolio website built for a Computer Science Student & Web Engineering Intern. Designed with a deep midnight slate aesthetic, modern glassmorphism UI elements, customizable CSS variables, and clean semantic HTML5.

🌟 Key Features

Responsive Layout: Optimized for all screen sizes (Mobile, Tablet, Desktop) using CSS Flexbox and CSS Grid.

Glassmorphism UI: Soft translucent cards with glowing gradients and backdrop blur effects.

Dark & Light Mode: Built-in theme switcher using CSS variables (:root) and lightweight JavaScript.

Skill Filtering: Dynamic skill tabs allowing visitors to filter by Languages, Web Technologies, and Tools & Databases.

Interactive Contact Form: Complete with interactive form fields and success notifications.

Semantic HTML5: Built using SEO-friendly and accessible HTML tags (<header>, <nav>, <main>, <section>, <article>, <footer>).

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6+)

Layout Engines: CSS Flexbox & CSS Grid

Fonts: Plus Jakarta Sans & Fira Code via Google Fonts

Icons: FontAwesome 6
